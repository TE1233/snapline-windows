# Snapline 0.5.0 本机验证

- 新增悬挂便签，暖黄、薄荷绿、淡紫三种纸色；截图和便签共同按创建时间分页排列。
- .NET Framework 4.8 编译通过，版本 0.5.0.0，EXE 108544 字节。
- 便签存储测试通过：中文、emoji、多行文字、纸色和 ID 重启恢复；编辑保留创建顺序；保存中断时回滚；超过 60 张截图和清空截图均保留便签；仅删除所选便签；过长输入不会覆盖已有内容；损坏文件保留原记录。
- 本轮截图存储、外部来源排除、Ctrl+B 路由、取消和过期结果、缓存编辑、自动收起、固定显示和快捷键冲突集成验证通过。
- 新建按钮、编辑框、换纸色和完成按钮通过实际运行窗口的 UI Automation 操作；直接完成时保存最新文字和纸色。
- 向实际便签投递双击鼠标消息，打开编辑窗口成功；编辑自动保存并重启恢复；空白新便签关闭后丢弃。
- 实际鼠标悬停打开完整文字预览，移开后关闭；预览文本与所保存的中文、emoji、多行文字一致。
- 右键菜单可见复制文字与删除操作。删除弹出确认，选择否保留便签，选择是只删除所选便签，其他记录保持不变。
