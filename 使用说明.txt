截图晾台 Snapline 0.5.0 — Windows 版

双击 Snapline.exe 启动，保留同目录的 Snapline.exe.config。
需要系统 .NET Framework 4.8，无需安装开发工具。

Ctrl+B：使用晾台的框选界面，拖动选区并松开，自动挂上晾台，同时复制图片。
Esc 或右键：取消截图，不添加图片，也不改动剪贴板。
只自动收集 Ctrl+B 截图。微信截图、Win+Shift+S、普通复制图片和外部截图文件均不会自动加入。
卡片或托盘的「截图（仅复制）」按钮：只截图并复制，不自动挂上。
托盘备选 Ctrl+PrtSc、Shift+PrtSc 也仅复制；恢复 Ctrl+B 后才自动收集。
Ctrl+B 也常用于加粗；需要加粗时可在托盘关闭截图快捷键。

「操作提示」挂在图片右边，悬停查看说明。
双击托盘图标或点「展开 / 收起」：临时展开，留 3 秒供鼠标移到晾台。
鼠标在晾台内保持显示，离开约 0.7 秒自动收起。
托盘「固定显示」：勾选保持显示，取消后恢复自动收起。
Ctrl+Alt+T：展开并固定 / 收起。
鼠标停在屏幕顶部约 0.3 秒：临时展开。

悬停截图：放大预览；移开、点击、拖动或收起时关闭。
单击图片：复制。双击：打开查看。长按：用画图编辑缓存副本。
拖出：按 Windows 规则复制或移动 PNG。
右键图片：另存为、复制 PNG 文件、移除等。
托盘「导入图片」：可以主动选择图片手动加入。
天空蓝晾衣绳中间下垂，截图和便签一起排列，可滚动鼠标或用两端箭头切换。

便签：点「操作提示」里的「＋ 便签」，或托盘「新增便签」。
暖黄、薄荷绿、淡紫三种纸色；支持多行文字，停下输入后自动保存到本机。
「完成」、Ctrl+Enter 或 Esc：保存并收起编辑窗口。
双击便签：继续编辑。悬停：看全文，长内容可滚动；移开关闭。
右键便签：编辑、复制文字、删除。点便签角上的 × 也可删除，删除前会确认。
便签重启后仍在；刚新建但未写字的空白便签关闭后丢弃。
按创建时间排列，编辑不会改变位置。每张最多支持 20000 个字符。

不再监听外部剪贴板或截图文件夹。旧自动收集设置不会重新启用。
编辑已有缓存图片仍会更新卡片。
截图最多保留 60 张，移除或清空截图只删除应用副本，保留原文件，不删除便签。
数据：%LOCALAPPDATA%\Snapline；便签文件为其中的 notes.json。错误日志：该目录下的 error.log。
完全本地运行，不联网、不上传、不修改 Windows 截图设置，不设置开机启动。
第三方应用粘贴和拖放取决于其支持的格式。本地构建，未做数字签名。

独立 Windows 实现，交互灵感来自 Alejandro Buján 的 Tendedero： https://github.com/alejandrobujan/tendedero。
使用自行绘制的图标与新的名称。
